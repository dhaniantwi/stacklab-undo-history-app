THE DATA STRUCTURE BEHIND THE APP

How stacks protect your work

A stack follows LIFO (Last In, First Out). When you edit your document, the application keeps previous states in an undo stack. Undo removes the latest available previous state and restores it. Redo uses a second stack to restore changes you have undone.

Push

Add a document state to the top of a stack.

Pop

Remove the state at the top of a stack.

LIFO

The most recently stored state is handled first.

Other real-world stack applications

  • Undo and redo in document editors and design software.
  • Browser navigation and previously visited pages.
  • Function calls and recursion in programming.
  • Expression evaluation and syntax checking.
  • Backtracking in puzzles, games, and maze solving.
